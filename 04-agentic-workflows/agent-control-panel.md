## What Juno Is Doing

Insight synthesis. Level 1, function-calling assisted autonomy: when a PM asks a scoped product question, Juno runs the existing insight-brief harness with one single-agent ReAct loop, chooses among its four approved tools without approval for each call, and returns a private brief for PM review. Level 2 is deferred because the current PRD has no recurring trigger or durable private review delivery. Primary failure mode: silent failure when a source read fails but the brief looks complete.

## Four Levers

**Stop Conditions** (Loop):

max_steps: 5 total model/tool turns per run, including any retry or focused follow-up. Hard limits: 30 seconds wall clock and $0.20 model-plus-tool cost. Abort normal completion on an empty scoped search; permission denial; any required source missing (retry once only for a transient read error); two failed reads of the same source; unresolved source conflict; failed verification; or a claim without a retrievable supporting passage. Done only when the private brief is at most 500 words, has at most three findings, and every factual finding passes citation verification.

**Structured Tool Outputs** (Tools):

All four calls return {run_id, tool, status: ok|error, error_code, elapsed_ms}; an error is never treated as empty evidence. search_sources returns {result_count, source_ids, scope_checked}; result_count=0 stops the run. read_sources returns up to five per-source records {source_id, access: allowed|denied, read_status: ok|error, event_date, updated_at, version, passages[]}; any required source with denied/error/zero passages is a coverage gap. draft_insight_brief returns {draft_status, word_count, finding_count, claim_to_source_span[]}. check_brief returns {check_status: pass|fail, unsupported_claims[], missing_sources[], conflicts[], format_errors[]}; only pass permits a complete private brief.

**Confidence Thresholds** (Verification):

High: the PM’s question and approved source scope are intact, all required sources are accessible, every factual finding has a retrievable source span with ID and date, any current-status source was updated within seven days, and check_brief passes; Juno may show a complete private draft. Medium: a required source is missing or stale, or evidence coverage is incomplete; stop normal completion and show a labeled partial brief with the gap and a PM question. Low: access is denied, sources conflict, a claim lacks support, or verification fails; stop without an asserted unsupported finding and hand the trace and reason to the PM. No numeric model confidence score substitutes for these gates.

**North Star** (Context):

At every step, answer only the PM’s current question by turning authorized product signals into a concise private insight brief that separates observations from hypotheses, cites each factual finding, and names evidence gaps; never invent a root cause, priority, owner, delivery date, or commitment, and never write to shared systems or send externally.

## Rules of Engagement

**Agency Permission:**

After the PM starts a scoped brief, Juno may search, read, draft privately, and verify without approval for each tool call. It may choose which in-scope source to read next, with at most one focused follow-up. It cannot change the question or source scope; assign priority, owner, or date; write to tickets, roadmap, or CRM; or send or publish. The PM decides whether and how to use the draft.

**Access Control:**

Run under the requesting PM’s existing access, restricted to that PM’s current question and approved RocketShip sources. search_sources may search only that scope; read_sources may fetch at most five authorized source IDs per batch, with access checks on every read. No reporting-database query, unrelated corpus, Slack, email, ticket, roadmap, CRM write, or external publishing tool. Re-fetch the latest authorized version at the start of each run; task excerpts and draft expire when the task ends or after 30 minutes idle, and no cross-run factual memory is written.

**Fallback Protocols:**

On a transient read error, retry that read once within the five-turn, 30-second, and $0.20 caps; a second failure stops normal completion. Never retry permission denial, empty evidence, source conflict, or failed verification. Return a private, explicitly PARTIAL result containing run_id, completed steps, source IDs/dates checked, the exact missing or conflicting evidence, error_code, and one concrete question for the PM. Preserve supported findings only; suppress unsupported claims. Do not silently substitute an old cached source or start another run automatically.

**Checkpoints:**

At the start of each brief, the PM supplies the question and determines its source scope. Every complete or PARTIAL result appears only in that PM’s private task view; the PM reviews evidence and meaning before using it for prioritization, a shared record, or external communication. A coverage gap, conflict, permission denial, or verification failure stops normal completion and requires PM clarification or a new run. Any expansion of question, source scope, or permissions requires a new PM instruction.
